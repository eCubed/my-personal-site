Centering with Flex Containers

We'll build upon stacks with vertical and horizontal alignment.

We created a modifer class --centered that would work with both vertical and horizontal stacks. Let's start with the horizontal scenario, which is the most familiar. As we expected, it will align items horizontally. The --centered modifier class also did specify align-items: center but that wouldn't apply because we have only one row.

Now, let's investigate what happens when we have the vertical stack and we want to apply the --centered modifier. We see that it centered each item in the horizontal direction as expected. Now, intuitively, we expect that it should center vertically, too but it doesn't. Recall that by default, a parent container's height is driven by the heights of its children. So, there would not be any vertical room for the parent to center its children.

One unobvious and often confusing thing is the application of justify-content and align-items. We often automatically think that justify-content applies only to the horizontal direction and align-items applies only to the vertical direction. The reality is, justify-content applies to the flex-direction specified.

When we have flex-direction: row;, justify-content applies to the horizontal direction, and align-items would apply to the vertical direction.

However, when flex-direction: column;, justify-content now applies tto the vertical direction and align-items would apply to the horizontal direction.

So, in our vertical stack container, we see that it center-aligned each item horizontally. And it's the align-items that caused the horizontal centering.

To see the vertical centering, we'll need to explicitly assign a height to the container - one we know that is larger than what the children would push its parent. For demonstration, we'll apply an inline style. Since the flex direction is column, justify-content achieved the vertical centering.

The --fit modifier class honored the explicit height and did not shrink wrap in the vertical direction. It did shrink wrap in the horizontal direction.

The CSS for what we've achieved with stacks, including shrink wrapping and centering are defined below:

        .stack {
          display: flex;
          flex-direction: column;
          gap: var(--space-md);

          &.--horizontal {
            flex-direction: row;
          }

          &.--fit {
            width: fit-content;
          }

          &.--centered {
            justify-content: center;
            align-items: center;
          }
        }
